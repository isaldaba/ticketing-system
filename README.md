# 🎫 L1 HelpDesk Ticketing System

A simple **L1 Support Ticketing System** built with **Laravel, Inertia.js, Vue 3, and TailwindCSS**.
This system allows teams to manage support tickets efficiently with role-based access and status tracking.

## 🚀 Features

* 🎫 **Ticket Management**

  * Create, assign, and track support tickets from submission to resolution.

* 👥 **Role-Based Access**

  * Admins manage tickets and staff.
  * Staff members handle assigned tickets.

* 📊 **Ticket Status Tracking**

  * Monitor ticket statuses:
  * Open
  * In Progress
  * Resolved
  * Closed

* ⚡ **Priority Levels**

  * Low
  * Medium
  * High
  * Critical

* 🔐 **Authentication**

  * Secure login and registration using Laravel Breeze.

---

## 🧩 Roles

### Admin

* Manage all tickets
* Assign tickets to staff
* Manage staff accounts
* Configure system settings
* View analytics

### Staff

* View assigned tickets
* Update ticket status
* Add notes and responses
* Mark tickets as resolved
* View personal dashboard

---

## 🛠 Tech Stack

* **Backend:** Laravel
* **Frontend:** Vue 3 + Inertia.js
* **Styling:** TailwindCSS
* **Authentication:** Laravel Breeze
* **Database:** MySQL
